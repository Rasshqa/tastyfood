# UI Audit - Menu Halaman Padang Rice
**Date:** 2026-10-07  
**Page:** `/menu`  
**Mode:** AFTER (audit existing design)

## Design Dials (inferred from brief)
- **ENERGY:** 2 (balanced, clean modern restaurant)
- **RHYTHM:** 2 (consistent with subtle variation)
- **MOTION:** 1 (minimal, focus on content)

## Findings

### HIGH Priority (Hard Gate / Functional)

**#1 - Card height excessive (R-31 - no written reason for layout)**
- **Issue:** Cards have unnecessary vertical whitespace, making content feel scattered
- **Impact:** Poor scanability, users must scroll more than needed
- **Rule:** R-31 (every decision needs reason), C-1 (intentionality)
- **Fix:** Reduce card padding, optimize image aspect ratio to 4:3, tighten content spacing

**#2 - Mobile responsiveness unknown (R-03)**
- **Issue:** Cannot verify from screenshot if mobile layout works correctly
- **Impact:** Potential horizontal overflow, broken navigation on mobile
- **Rule:** R-03 (mobile must be perfect)
- **Fix:** Test and fix mobile breakpoints (<=767px, 768-1199px, >=1200px)

**#3 - Visual hierarchy weak in cards (C-1, R-31)**
- **Issue:** All text elements have similar visual weight
- **Impact:** Hard to quickly scan menu name, price, description
- **Rule:** C-1 (intentionality), R-31 (reason for typography)
- **Fix:** Establish clear hierarchy: name (largest/bold) > price (bold) > category (small uppercase) > description (muted)

### MEDIUM Priority (Purpose-Gate)

**#4 - Sidebar filter feels template-default (R-05, R-20)**
- **Issue:** Generic sidebar layout, no unique identity
- **Impact:** Feels like e-commerce template, not restaurant
- **Rule:** R-05 (avoid AI template layouts), R-20 (visual identity)
- **Fix:** Redesign sidebar with restaurant-appropriate styling, modern radio buttons, subtle borders

**#5 - Grid spacing inconsistent (R-31)**
- **Issue:** Gap between cards varies visually
- **Impact:** Layout feels unpolished
- **Rule:** R-31 (spacing must have reason)
- **Fix:** Use consistent grid gap (20px), ensure equal column widths

**#6 - Price range slider generic (R-04, R-20)**
- **Issue:** Default range slider appearance
- **Impact:** Doesn't match restaurant aesthetic
- **Rule:** R-04 (elements must be relevant), R-20 (identity)
- **Fix:** Style range slider with custom track, thumb, and labels

### LOW Priority (Quality Locks)

**#7 - Category pills lack hierarchy (R-09)**
- **Issue:** Category filter pills all same weight
- **Impact:** Active state not clear enough
- **Rule:** R-09 (badges must have functional purpose)
- **Fix:** Make active category more prominent (bg color, not just border)

**#8 - Card selection indicator too small (R-26, C-2)**
- **Issue:** Add button (○) nearly invisible in bottom-right
- **Impact:** Poor UX, hard to click
- **Rule:** R-26 (interactive elements must work), C-2 (functional completeness)
- **Fix:** Replace with clear "Tambah" button or larger +/− quantity controls

**#9 - Sidebar and content alignment (R-31)**
- **Issue:** Sidebar and grid don't feel like cohesive system
- **Impact:** Layout feels disconnected
- **Rule:** R-31 (layout must have reason)
- **Fix:** Align sidebar top with content header, consistent gap (28-32px)

**#10 - Typography inconsistent (R-06, R-31)**
- **Issue:** Font sizes and weights vary without clear system
- **Impact:** Unprofessional appearance
- **Rule:** R-06 (typography must improve readability), R-31 (reason required)
- **Fix:** Establish type scale: category (11px uppercase), name (18px bold), price (16px semibold), description (14px regular muted)

## Recommendations

**Keep (don't change):**
- Header/navbar structure
- "PADANG RICE" branding
- Category filter concept
- Price range filter concept
- 3-column grid on desktop
- Menu data, images, functionality

**Fix:**
- Card proportions and spacing
- Visual hierarchy within cards
- Sidebar styling and modern controls
- Interactive element visibility
- Mobile responsiveness
- Typography system

**Priority order:**
1. Fix #1 (card height/spacing) - biggest visual impact
2. Fix #3 (visual hierarchy) - improves scanability
3. Fix #8 (selection indicator) - improves UX
4. Fix #4 (sidebar redesign) - polish
5. Fix #2 (mobile) - ensure it works
6. Fix #5, #6, #7, #9, #10 (consistency polish)
